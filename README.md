# Section 700 Hexane Recovery Dynamic Simulator

Mô phỏng đào tạo tương tác dựa trên Process Description và PFD trong PowerPoint.

## Chạy local
Mở `index.html`, hoặc dùng VS Code Live Server.

## Deploy GitHub + Vercel
1. Tạo repository mới trên GitHub.
2. Upload toàn bộ file trong thư mục này vào root repository.
3. Vào Vercel > Add New Project > Import repository.
4. Framework Preset: Other; Build Command để trống; Output Directory: `.`
5. Deploy.

Lưu ý: mô phỏng phục vụ đào tạo, không thay thế DCS/SOP/P&ID đã phê duyệt.
